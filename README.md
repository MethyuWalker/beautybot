# Beauty Salon Telegram Bot

Подготовлена автоматическая сборка Windows EXE через GitHub Actions.

**Важно:** перед сборкой добавьте в корень репозитория три файла из исходного ZIP:
`bot.py`, `database.py`, `web_admin.py`.

Затем откройте **Actions** → **Build Beauty Salon Bot for Windows** → **Run workflow**.
Готовый архив `BeautySalonBot-Windows` появится в Artifacts.

Подробная инструкция по сборке и первому запуску: [README_RU.txt](README_RU.txt).

Не загружайте в репозиторий настоящий токен Telegram-бота или файл `.env`.
