BEAUTY SALON TELEGRAM BOT — СБОРКА WINDOWS EXE

Точка входа проекта — bot.py. Сборка выполняется GitHub Actions на Windows.

ПЕРЕД СБОРКОЙ:
В корне репозитория должны находиться исходные файлы:
  bot.py
  database.py
  web_admin.py

Также в репозитории уже подготовлены requirements.txt и
.github/workflows/build.yml.

КАК ПОЛУЧИТЬ EXE:
1. Добавьте три исходных Python-файла в корень репозитория.
2. Откройте вкладку Actions.
3. Выберите "Build Beauty Salon Bot for Windows" и нажмите Run workflow.
   Workflow также автоматически запускается после push в main.
4. Дождитесь завершения и откройте запуск workflow.
5. В разделе Artifacts скачайте "BeautySalonBot-Windows".

ЗАПУСК У ЗАКАЗЧИКА:
1. Распаковать скачанный артефакт в отдельную папку.
2. Запустить BeautySalonBot.exe.
3. При первом запуске в консоли ввести токен Telegram-бота, Telegram ID администратора,
   телефон салона и пароль веб-панели.
4. Настройки сохраняются в .env, база данных — в beauty_salon.db рядом с EXE.
   Эти файлы нельзя удалять после настройки.
5. Локальная веб-панель: http://127.0.0.1:8080.

Для работы Telegram-бота нужен интернет и постоянно включённый компьютер.
Не добавляйте настоящий токен в GitHub. Не публикуйте файл .env.
